01. Objetivo

Um site inteiro sem framework#

A proposta era construir um portfólio completo só com o que o navegador entende: sem biblioteca, sem etapa de build e sem instalação. Abrir o index.html já é rodar o projeto.

  1. HTML semântico
  2. tokens de CSS
  3. componentes
  4. JavaScript só para comportamento

02. Estilo

Um arquivo de tokens decide as cores#

Nenhuma cor é escrita direto nos componentes. Tudo sai de variáveis CSS, e o tema claro só troca o valor delas. Projetos e cases mudam a cor de destaque pelo atributo data-tom.

tokens.css

:root {
  --fundo: #0b0e13;
  --ambar: #f2b155;
  --tom: var(--ambar);
}

[data-tema="claro"] {
  --fundo: #f5f6f8;
  --ambar: #a45a00;
}

[data-tom="case"] {
  --tom: var(--verde);
}

03. Comportamento

O JavaScript entra por último#

O conteúdo inteiro está no HTML e continua legível com o JavaScript desligado. Os scripts são pequenos e cada um cuida de uma coisa só:

  • trocar o tema e lembrar a escolha;
  • abrir e fechar o menu no celular;
  • filtrar a listagem por categoria;
  • destacar no índice o capítulo que está sendo lido;
  • validar o formulário de contato.
